# Sung Hyun Kim — Personal Website

Minimal white portfolio for 김성현 (Sung Hyun Kim), AI Engineering @ Sookmyung Women's University.

Pages
- `index.html` — home: short intro, research interests, recent updates, selected projects, contact
- `about.html` — interests, education, experience timeline (with photos), awards & certifications, skills
- `projects.html` — all projects with filters, GitHub links and case-study modals

Edit content in **`assets/data.js`** only (KO/EN for every string: `news`, `areas`, `experience`, `projects`, `awards`, `certs`, `skills`).
Shared styling lives in `assets/site.css`, behaviour in `assets/site.js`. Photos: `assets/profile.jpg`, `assets/photos/` (full), `assets/thumbs/` (square), `assets/og.jpg` (link preview).
