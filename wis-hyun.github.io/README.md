# Sung Hyun Kim — Personal Website

Minimal white portfolio for 김성현 (Sung Hyun Kim), AI Engineering @ Sookmyung Women's University.

- `index.html` — the whole site (HTML + CSS + JS in one file). Edit the `DATA` object at the top of the `<script>` to change content (KO/EN).
- `assets/profile.jpg` — profile photo · `assets/photos/` full-size activity photos · `assets/thumbs/` square thumbnails · `assets/og.jpg` link preview image.

Features: KO/EN toggle, light/dark theme, scroll progress, animated counters, expandable experience timeline with photo lightbox, project filter + case-study modal, copy-email, back-to-top, SEO/OpenGraph/JSON-LD, print stylesheet.
